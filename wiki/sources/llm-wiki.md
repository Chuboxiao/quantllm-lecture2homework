# LLM Wiki 方法在本作业中的用法

来源：[用户提供的原文](../../llm-wiki.md)。本页为方法摘要，不是对交易源码的证据。

原文要求把资料、整理后的知识、维护约定分开。我们的对应位置是 `raw/`、`wiki/` 和 [AGENTS.md](../../AGENTS.md)。具体文件夹名称由项目决定。

新增资料时，先阅读并写来源摘要，再更新概念页和链接。提问得到有价值的解释时，把结论写回笔记。定期检查矛盾、失效链接和遗漏，并记录尚未核实的内容。原始资料不随解释一起修改。

[index.md](../index.md) 是内容目录，[log.md](../log.md) 是时间记录。两者都不替代资料本身：回答代码行为时仍需回到固定版本的源码。

用户已有 Obsidian 配置，保持原样；标准 Markdown 链接也可在其他编辑器及 GitHub 阅读。不需要搭建知识库服务器。

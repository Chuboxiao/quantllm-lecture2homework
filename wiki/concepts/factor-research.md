# 因子研究：概念与本轮结果

本页解释因子研究的概念。本项目先用 AU0 黄金期货日线做 12 个均线动量候选的早期练习，随后使用股票历史数据多次研究；最新四轮分别检验 10、12、12、15 项多均线与价格行为候选，尚未找到通过独立时间检验的理想因子。正式结果见[第二部分作业报告](../../reports/第二部分作业报告.md)。

Clue 是想检验的市场现象，因子是由当时已知数据计算的分数，评价是比较分数与后续表现的关系。老师演示用跳空动量作为 clue；本项目采用用户提出的“长短期均线关系”完成了一轮实验。

`vnpy_ctastrategy` 是单标的策略模块；老师提到的 `vnpy.alpha` 位于 `vnpy` 核心仓库。它们不等于同一套回测功能。核心项目的 alpha 可选依赖包含 Polars、Alphalens、机器学习库等，见 [pyproject.toml](https://github.com/vnpy/vnpy/blob/fa5206fe63836f3f8cd1ebd7168fbd19a5e2ff09/pyproject.toml#L1)。本轮只核对了依赖入口，未深入阅读 alpha 实现。

CTP 实时行情登录成功不会自动提供因子研究所需的历史数据。早期另取公开 AU0 日线进行练习；正式股票研究使用老师附带的历史缓存，四轮训练/验证只有一个候选初筛通过，而最终测试期信号平均收益为负，因此没有把任何公式标作可交易因子。

“反复尝试后找到历史表现好的公式”不等于已发现稳定规律；应保留全部候选和未参与调试的数据评价。

来源：[课程提示词](../sources/course-issue-2.md)。实施目录：[因子研究](../../projects/factor_research/README.md)。

## 长短期均线：当前候选 clue

用户提出的假设：短期均价相对长期均价走强时，未来价格是否倾向继续上涨？这属于趋势/动量方向，也应检验偏离过大时是否反而回归。

这里“因子”指用当时已经知道的数据计算的研究分数；“策略”还需要把分数转为交易、仓位与退出规则。例：`MA5 / MA20 - 1` 是均线相对偏离分数；金叉买入、死叉卖出是一套交易规则。分数 0.02 表示短均线高于长均线 2%，不是预测未来收益一定为 2%。

可研究的机制：均线相对偏离、偏离的变化速度、短长均线斜率是否同向、相对位置维持时间、成交量是否确认趋势。均线窗口的简单排列不等于发现多个独立规律。

老师的跳空动量例子：`当日开盘价 / 前日收盘价 - 1`。检验的是跳空之后的表现；已经发生的跳空收益不能算作开盘后策略赚到的收益。

因子没有统一固定的类别数量。动量、反转、波动、流动性等是常见价格/交易信息研究方向；股票还常见价值、规模、质量、成长等方向，不能照搬到期货。

研究前需确认数据标的、频率和预测期限。收盘数据算出的因子在收盘后才可用，不能据此假定能在同一收盘价成交。先划分研究/验证/最终测试区间，记录全部候选和相似度，不能反复看最终测试集修改公式。本次股票研究按四轮各 12 个候选的上限完成，最终测试期已揭示，不能再拿它反复调参挑公式。

参考：[时间序列动量论文](https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum)、[MSCI 因子分类示例](https://www.msci.com/research-and-insights/blog-post/creating-a-common-language-for-factor-investing)。上述均线公式是本项目教学候选，尚无有效性证据。

## 多条均线和价格行为：第一轮候选设计

第一轮设计前核对代码：当时已研究过 MA5/20、MA10/40、MA20/60、MA60/120 的距离、斜率、交叉、持续性；还把股价相对 MA5/10/20 的回撤／重新站上、日收益、成交量及收益波动与均线组合过。当时**尚未系统研究**四条均线同时排列的最弱一环，也少用 `open/high/low/close` 描述的突破、日内收回和真实波幅；这些方向后来已在本次四轮中检验。现有 BaoStock 前复权数据包含完整开高低收；3,294,309 行无空价、无 `high<low` 或 `close>high` 的行。这只证明输入字段可用，不证明信号有效。

下表是**第一轮运行前**写下的十个研究假设；用户随后明确授权新研究，本表已作为第一轮运行，结果见[均线价格组合研究](../../reports/第二部分作业报告.md)。定义 `M_n` 为截至信号日 `t` 的 n 日收盘均线；`C/O/H/L` 为当日收／开／高／低价；`x₊=max(x,0)`；`A=1(M5>M20>M60>M120)`，`T=1(M20>M60>M120)`。`H20⁻` 为 **t 前** 20 日最高价；`R20=(C−近20日最低价)/(近20日最高价−近20日最低价)`，这项区间包含 t 日；`D20=1−C/H20⁻`；真实波幅 `TR=max(H−L, |H−前收|, |L−前收|)`，`ATR_n` 为近 n 日 TR 均值。分母为零时分数记零。所有输入在 **t 日收盘后**才完整可知，最早按 `t+1` 价格评价。

| 假设 | 候选分数（非交易规则） | 与已试公式的区别 |
|---|---|---|
| 四层均线最弱一环 | `[min(M5/M20−1, M20/M60−1, M60/M120−1)]₊` | 三个间距必须同时为正，不能靠单层特别强掩盖另一层弱。 |
| 三层间距同步扩大 | `A × [min(Δ₅(M5/M20), Δ₅(M20/M60), Δ₅(M60/M120))]₊` | 原实验分别看斜率／加速；这里要求三层同时改善，可能显著减少信号。 |
| 均线先收敛再发散 | 令 `W=(M5−M120)/M120`；分数为 `A × 1(W[t−5]<W[t−10]) × [W[t]−W[t−5]]₊` | 测试多层均线先收窄、再扩张的状态变化。 |
| 长趋势中的价格突破 | `T × [C/H20⁻−1]₊` | 要求收盘突破此前 20 日高点；过去只看过简单均线交叉／相对位置。 |
| 均线排列与区间高位 | `A × [R20−0.8]₊` | 衡量收盘处于近期完整高低区间的什么位置，不只看收盘距均线。 |
| 下探 MA20 后收回 | `T × 1(L<M20<C) × (C−M20)₊/ATR14` | 用当日最低价区分“盘中跌破又收回”与始终在均线上方。 |
| 适度回撤后强势收盘 | `T × 1(0.02≤D20≤0.08) × [R20−0.7]₊` | 回撤幅度相对过去高点定义，再看当天收盘位置；阈值只是待检验的固定假设。 |
| 均线向上且波幅收缩 | `A × [1−ATR5/ATR20]₊ × [M20/M60−1]₊` | 使用高低价及跳空构成的真实波幅，而不是此前的收盘收益标准差。 |
| 均线向上且波幅扩张 | `A × [ATR5/ATR20−1]₊ × (C−O)₊/ATR14` | 对照上一项：区分缩量式整理与当日强阳线伴随波幅放大。 |
| 开盘在 MA5 下、收盘收回 | `T × 1(O<M5<C) × (C−O)₊/ATR14` | 关注**同一天**开盘至收盘穿越 MA5；旧公式检查的是前收盘与当日收盘。 |

这些候选高度相关，尤其“突破／区间高位”和两种“收回均线”不能当作十个独立发现。旧四轮已结束；本轮是用户随后**单独授权**的新研究第一轮，不冒充旧研究第五轮。2008—2026 年结果均已在此前项目中看过，本轮即使表现为正，也不是新的独立时间样本。评估把股票自身收益及不确定性作为主问题，横截面排序作为辅助，并保留全部失败结果。设计动机与[经典均线／区间突破研究](https://onlinelibrary.wiley.com/doi/10.1111/j.1540-6261.1992.tb04681.x)及[均线和波动率分组研究](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=1656460)有关，但这些论文的市场、期限与组合规则不同，不能替代本项目检验。

## 用户提出的均线公式分类：已试边界

“研究过某一类”不等于该类的每一个具体公式都运行过。核对[早期均线状态研究](../../projects/factor_research/ma_followup.py)、[统一数据研究](../../projects/factor_research/ma_unified_research.py)、[最新四轮第一轮](../../projects/factor_research/ma_price_research.py)及[第四轮](../../projects/factor_research/ma_price_round4.py)：

| 分类 | 已实际检验 | 尚未直接检验的用户示例 |
|---|---|---|
| 距离 | `MA5/MA20−1` 等比值；用收益标准差缩放均线间距 | 对数变换、均线价差除以价格或 ATR、均线距离的自身历史分位 |
| 斜率 | 单根均线的多日变化率，以及短、长斜率之差 | 两个斜率的比值 |
| 变化／加速度 | 间距的 3/5/10 日变化、二阶差分、多层间距同步扩大 | 用户列出的其他窗口与极端阈值并未逐一检验 |
| 交叉状态 | 近期 5/10 日是否金叉、正间距维持 5/10 日、价格重新站上均线 | 精确的交叉后天数、窗口内交叉次数、交叉当日量能或 ATR 强度 |
| 多均线排列 | `MA5>MA20>MA60>MA120` 门控、三层间距最弱值、先收窄再扩大 | 所有两两有序对的比例、排列熵、四根均线的变异系数 |
| 收敛发散 | 间距扩大／缩小、先收敛后发散 | 均线差的滚动标准差、布林带式标准化、距历史极值回落 |
| 成交量／价格确认 | 均线间距结合量比、放／缩量、跳空、开收盘及日内位置 | “交叉时”量能确认的专门事件分数 |
| 横截面 | 同日股票排序、Rank IC、相对股票池收益差；主要仍看股票自身未来收益 | 多空组合收益及行业、市值、波动率中性化 |

`ln(MA_S/MA_L)` 在比值为正时与 `MA_S/MA_L−1` 顺序相同；若只比较同日排序，它不是独立的新排序线索。斜率比值在分母接近零时可能不稳定，须先定义缺失和截断规则。以上“尚未检验”只标明研究覆盖范围；最新研究已达到用户限定的四轮上限，不能把补测当作第五轮，也不能用已看过的历史时期冒充独立验证。

## 绝对涨跌、横截面比较与老师的 harness

2026-09-24 用户明确：主要关心均线条件出现后股票自身是否上涨、交易是否赚钱。此前建议直接转向横截面比较过快；后续评价应围绕这个目标设计。

用户随后明确：老师的 harness 只作为参考，不要求原样复现。接下来先核验可用股票数据，再建立符合绝对收益目标的实验。数据准备的重点是数据来源、覆盖和口径，而非挑选容易产生漂亮回测的股票；不必强制使用沪深300，但股票池规则应事先固定，并说明退市、历史成分及存续偏差的处理。下载包实际附带两个缓存文件，并非只有代码中的路径；现已完成表内基础核查，见[股票数据核查](../../reports/第二部分作业报告.md)。

用户进一步同意同时研究绝对涨跌与横截面比较。两者不冲突：相同因子、相同日期和未来收益定义，可分别评价股票自身后续收益与同日排序能力。按当前目标，绝对收益为主、横截面为辅助诊断；最终同时披露，不按测试结果切换主目标。绝对收益需要保留原始收益口径，不能把每日标准化后的 label 当作真实收益。训练/验证/测试区间共用，切分处隔离跨界的持有期；多股票同日观测和重叠持有期并非独立样本，不能把股票×日期直接当成独立试验次数。

- 时间序列/绝对收益研究：检查信号出现后的未来收益、上涨比例、平均盈利与亏损、扣除成本后的期望收益，并与不筛选信号时的基准比较。
- 横截面研究：同一天给股票打分，检查高分股票未来是否比低分股票表现好。高分组跌 2%、低分组跌 5% 也可能是相对预测成功，不能据此说买入赚钱。
- 两者都可以研究因子的预测能力。使用多只股票重复验证，不等于必须把目标改成横截面排名；上涨胜率也不能替代盈亏幅度与成本。

首次只读检查老师下载包 `20260918北京大学-VeighNa量化平台-课件代码/pku_demo/projects/alpha_mining_demo/` 的 README、配置及评估/报告源码，未执行程序、未加载 pickle、未接入任何账号。该本地分发包未核验 Git 提交号；以下结论对应本次下载副本。

Harness 是组织实验的程序与约定，不是固定文件格式：Agent 把候选公式写入 `candidates.json`，调用 `eval_factors.py`，读取 `metrics.json`，写 `notes.md` 并决定下一轮，最后调用 `final_report.py`。`config.json` 固定数据、时间划分和预测目标；底层使用 `vnpy.alpha`。Wiki/AGENTS 提供上下文和规则，只有 Markdown 本身不能执行评估。

老师这个实例默认按日横截面计算 IC/RankIC，label 是 T+1 收盘到 T+3 收盘收益。`directional_win_rate` 是每日 IC 符号与该区间平均 IC 符号一致的比例，不是买入后上涨的概率。默认 `eval_test=false`。筛选统计和分组收益分析也不能等同完整的逐笔交易回测。

README 称数据覆盖 859 只沪深300股票；实际读取缓存为 819 只，不能把 README 数字当作事实。历史成分区间也为 819 只，外部名单准确性尚未独立核验。`lab_path` 指向老师 Windows 的 `D:/pku_demo/raw/alpha_researcher/lab/csi300`，下载副本未包含该原始目录，但附带约 235 MB 的基础数据集缓存及成分过滤缓存。现已用独立核查程序成功读取缓存，无需运行老师的 harness。实际为 2,668,723 行日线；OHLC 已按各股首个收盘价归一化，VWAP 未同步缩放，复权方式仍待确认。还有零成交量和少量成员/行情例外，详见[核查报告](../../reports/第二部分作业报告.md)。

SimNow 是期货仿真交易环境，不提供此研究需要的沪深300历史股票成分与日线数据。VeighNa 提供研究/回测代码，历史数据另由数据服务或本地数据提供；历史回测无需连接 SimNow。历史成分是各日期当时的成员名单，不能用今天的名单直接代替过去名单。

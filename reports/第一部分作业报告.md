# 第一部分作业报告：最小 CTP Demo 与个人 SimNow 仿真交易

更新：2026-09-24。**已在个人 SimNow 仿真账号完成 1 手黄金开仓、60 秒自动平今、成交回报和最终空仓核验。**未使用老师账号，也没有连接真实资金账户。

## 实现

`projects/ctp_demo/demo.py` 直接调用 `vnpy_ctp.api.MdApi` 和 `TdApi`，完成连接、认证、登录、结算确认、合约查询和行情订阅。00:10—00:11 的只读运行收到 583 条行情，最终观察到持续更新的黄金、白银、铜合约；具体见 [行情汇总](live-summary.json)。

`projects/ctp_demo/trade.py` 在相同底层接口上增加单次价格触发交易。交易前确认连续交易状态、结算、合约、双时钟行情新鲜度（均不超过 2 秒）、买卖盘口、涨跌停范围、保证金、手续费、资金、目标合约持仓与活动委托。只允许上期所黄金或白银的 1 手多头；本次选择 `au2612`。用户设定的模拟亏损触发额为 100,000 元，成交后最长持有 60 秒，平仓使用“平今”。亏损触发额是市价观察规则，跳价、延迟或流动性不足时实际亏损可能超过它。

程序在每次发单前把意图写入 SQLite，并记录 `OrderRef`、`OrderSysID`、行情、报单、成交和错误。对 3 秒无明确受理回报、10 秒挂单未成交、断线和重启设置冻结或撤单规则；已有发单意图时拒绝再次开仓。原始日志、账户查询和完整订单引用仅留在本地 `reports/local/` 与 `data/trade_state/`，不进入 GitHub 提交。

关键边界在程序中有明确规则：最新价必须为正且有限，买一、卖一及至少 1 手报价量均有效；卖一为空不猜价。行情时间戳和回调入队时间均不得过期超过 2 秒，重复或倒序时间戳不触发。只有本地交易时段与 CTP 连续交易状态一致、结算已确认时才允许开仓；状态未知或距休市不足 120 秒则不开仓。保证金按涨停价保守估算，检查账户资金、既有持仓、活动委托与涨跌停界限。受理回报不明时先冻结查询，不把超时理解为“没有成交”。断线重连只核对订单和持仓，不重新触发已发过的单；平今失败或状态不明时转人工核对。

## 真实仿真验收

第一次使用固定阈值 929.72，180 秒无有效上穿，0 发单。第二次在风控就绪后按首条有效价上方两个最小价位固定阈值 931.58；虽然随后价格上涨，首次穿越发生在盘口不合格时，180 秒仍 0 发单。于是按用户允许的备选方案，保留“风控就绪后固定阈值”的规则，将触发条件改为**连续两条不同时间戳的有效行情高于固定阈值**；每次盘口检查失败便清零计数。25 项规则/模拟执行测试通过后启动第三次，也是最后一次交易尝试。

| 环节 | 本机事件与 CTP 回报 |
|---|---|
| 触发 | 本机 02:01:20 固定阈值 932.48；02:02:02 两条有效行情满足条件 |
| 开仓 | 本机约 02:02:02 收到受理和成交回报；CTP 回报的成交时刻为 02:02:01，买入开仓 `au2612` 1 手，成交价 932.50 |
| 自动平今 | 持仓满约 60 秒，本机约 02:03:02 收到成交回报；CTP 回报的成交时刻为 02:03:01，卖出平今 1 手，成交价 932.24 |
| 最终核验 | 再查账户、委托、成交与持仓：两张订单均为全部成交，目标合约持仓 0，无活动委托；程序状态为 `closed`，没有冻结 |

本机事件时间与 CTP 回报时间来自不同钟源和记录粒度，不能仅凭秒数先后推断订单事件顺序。

该合约每手 1000 克，价差造成毛损益约 −260 元；柜台显示手续费 2 元、平仓盈亏 −260 元，余额变化 −262 元。上述是**仿真交易**的一次执行验证，不是策略盈利测试。发单前按涨停价保守估算保证金 150,052 元、费用预留 2 元，账户可用资金检查通过。此次退出由 60 秒规则触发，未触及 100,000 元止损额；止损分支只经过模拟测试，没有真实触发验收。

证据保留在本机 `reports/local/trade_20260924_020112_748938/` 的事件和汇总文件，以及持久化订单账本。公开提交不包含个人账号、密码、原始会话文件或资金快照。

## 复现与局限

在项目根目录先运行 `.venv/bin/python projects/ctp_demo/demo.py` 查看行情；`.venv/bin/python projects/ctp_demo/trade.py` 默认只读预检。显式加 `--execute --plan configs/local/trade-plan.json --duration 180` 会尝试发送仿真订单，但本次账号已有持久化发单意图，程序会拒绝自动重跑；**不要删除账本来重复发单**。环境为 Python 3.12.14、vnpy 4.4.0、vnpy_ctp 6.7.7.2，Mac arm64 上需要本地编译的 CTP 动态库。短时成功不证明全天稳定性、任何断线后可自动接续、真实市场成交质量或可盈利性。

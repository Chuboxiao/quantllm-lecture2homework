# 第二讲作业：CTP 模拟交易与股票因子研究

两项作业各有一份正式报告：[第一部分：最小 CTP Demo 与 SimNow 仿真交易](reports/第一部分作业报告.md)、[第二部分：股票均线与价格行为因子挖掘](reports/第二部分作业报告.md)。截至 2026-09-24 均已在本地整理，**尚未提交到 GitHub**。源码学习入口见[架构笔记](wiki/concepts/architecture.md)。

| 目录 | 用途 |
|---|---|
| `projects/ctp_demo/` | 底层 CTP 行情 Demo、单次价格触发交易、规则测试 |
| `projects/factor_research/` | 股票数据核查、历次均线因子研究与早期黄金练习 |
| `wiki/` | 概念解释与固定源码阅读笔记 |
| `reports/` | 两份 Markdown 正式报告及机器可读的验证证据 |
| `raw/` | 课程原件及五个官方仓库的本地源码副本、来源清单 |
| `configs/`、`data/` | 无凭据配置样例；个人配置和历史数据仅保留本地 |

第一项在个人 SimNow 仿真账号完成 1 手黄金开仓和约 60 秒后的自动平今，最终查询为空仓。第二项经历数据核查、去除事后筛选及多次均线线索研究；最近一项新授权研究为四轮 49 个候选（含对照），**没有找到通过独立验证的理想因子，也未宣称可交易利润**。完整计划、失败候选和诊断数字以 JSON 保留，原始行情不入库。

**提交前**按 [提交说明](提交说明.md) 检查文件。账号配置、原始行情、CTP 会话与个人运行日志被 `.gitignore` 排除；不要删除 `data/trade_state/` 的订单账本以重跑交易。
